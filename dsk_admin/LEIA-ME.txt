DSK - ÁREA ADMINISTRATIVA (clientes e financeiro)

1) BANCO (MySQL Workbench, conectado como root)
   - Para recriar do zero, abra somente db/init.sql na pasta raiz "dsk" e
     execute o arquivo inteiro.
   - O script apaga e recria apenas o banco projetoindividual. Não é preciso
     apagar o banco manualmente; os demais bancos não serão alterados.
   - O banco novo cria somente o administrador dsk.danillo@gmail.com.
   - db/init.sql é o único script SQL. Clientes podem se cadastrar pela aplicação.
   - Se uma versão antiga já criou a coluna pix_chave, confira com
     SHOW COLUMNS FROM projetoindividual.clientes LIKE 'pix_chave';
     e remova-a com ALTER TABLE projetoindividual.clientes DROP COLUMN pix_chave;

2) ARQUIVOS
   Copie as pastas deste pacote para dentro da pasta raiz "dsk" do projeto,
   aceitando substituir os arquivos que já existem:
     app/lib/admin.php            (NOVO)
     app/lib/mensalidades.php     (NOVO)
     app/lib/helpers.php          (alterado: cidade e telefone)
     app/lib/auth.php             (alterado: bloqueio de conta suspensa)
     app/lib/layout.php           (alterado: menu do admin)
     app/lib/password_reset.php   (alterado: solicitações e senhas temporárias)
     public/index.php             (alterado: link "Esqueci minha senha")
     public/cadastro.php          (alterado: validação de cadastro)
     public/recuperar-senha.php   (NOVO: solicitar recuperação de senha)
     public/admin/dashboard.php   (substitui o anterior)
     public/admin/recuperacoes-senha.php (NOVO: atender solicitações de recuperação)
     public/admin/relatorio-clientes.php (NOVO)
     public/admin/clientes.php    (NOVO)
     public/admin/financeiro.php  (NOVO)
     scripts/gerar_mensalidades.php (NOVO)
     public/cliente/dados-pessoais.php (NOVO)
     public/assets/css/style.css  (estilos administrativos)
     public/assets/js/language.js (NOVO: seletor de idioma)

   A recuperação de senha não envia mensagens por e-mail. O motorista solicita ajuda
   pela tela de login; o administrador recebe o alerta no Dashboard e, em
   Recuperação de senhas, gera uma senha temporária, exibida uma única vez para
   ser compartilhada por um canal seguro. Depois de entrar, o motorista altera a
   senha em Dados pessoais. A tabela de solicitações é criada automaticamente
   e também consta em db/init.sql para novas instalações.

   A tela Clientes permite criar, editar e excluir cadastros, alterar dados
   pessoais e redefinir o acesso/senha. Valores e cobranças de mensalidade ficam
   na página Financeiro, separados dos dados pessoais. Não há cálculo de comissão
   por rota.
   O cadastro valida cidade no formato CIDADE / UF e impede e-mail ou telefone
   duplicado. O cliente pode editar seu cadastro em Dados pessoais depois de entrar.
   O Financeiro registra as mensalidades da plataforma; não processa pagamentos
   nem cobra valores de rotas. Novos cadastros vencem no dia em que foram criados
   e recebem a primeira cobrança imediatamente. As próximas cobranças são
   geradas por scripts/gerar_mensalidades.php; agende esse script diariamente
   no Agendador de Tarefas do Windows com C:\xampp\php\php.exe e mantenha o MySQL
   ligado. Pix é apenas uma forma manual de marcar uma mensalidade como paga.

3) RODAR (igual antes)
   C:\xampp\php\php.exe -S 127.0.0.1:8000 -t public
   A conta administrativa é criada durante a instalação com uma senha de
   demonstração. Substitua-a por uma senha segura antes de publicar o sistema.

Observação: db/init.sql apaga os dados existentes em projetoindividual e
recria o banco. Os dados atuais são apenas testes, então podem ser descartados.
